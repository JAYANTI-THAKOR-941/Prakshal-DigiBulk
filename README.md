# Prakshal DigiBulk

Windows desktop WhatsApp campaign manager for Prakshal IT Academy. Official Meta Cloud API, opt-in contacts only. Node.js 22+ required. Run `npm install` and `npm start`; build on Windows with `npm run build`.

Use a currently supported Graph API version, phone number ID and access token. Create an approved marketing template in Meta before sending course promotions. Import Excel/CSV with `mobile,consent` columns; consent must be `yes`. Test with one opted-in recipient first. API charges apply. Acceptance is not delivery; delivery/read webhooks are not included. No QR automation or unlimited free sending. Never commit student data or credentials.
